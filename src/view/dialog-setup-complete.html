Try it with the example row

  • We've created the sheet with an example row for you
  • Select row 3 by clicking on the row number
  • Go to Brick Tracker menu → Fetch Data for Selected
  • Watch the data automatically populate!

Adding more sets

  • Use Add Set to Sheet for quick entry
  • Or manually enter set number, condition, status, and purchase price
  • Select the row(s) and click Fetch Data for Selected
  • The rest of the columns will be filled automatically
