Quick Start
▼
  1. Run Brick Tracker → Create Tracking Sheet (first time only)
  2. Add sets using Add Set to Sheet or enter manually
  3. Select rows and click Fetch Data for Selected to populate details
💡 Tip: The Condition column (Sealed/Open) determines whether "New" or "Used" pricing is set. Make sure to set it correctly!
Best Practices
▼
  • Use the Add Set to Sheet menu item to quickly add new sets
  • Enter set numbers without the "-1" suffix (e.g., use "10305" not "10305-1")
  • Select specific rows before fetching data for targeted updates
  • Use Fetch Data for Selected with no selection to update all sets
  • Keep the Quantity column updated to track multiple copies
  • Check the "Last Updated" column to see when data was last fetched
  • Use the Status dropdown to organize your collection (In Collection, Wishlist, etc.)
Things to Avoid
▼
  • Don't delete the tracker sheet - it's tracked by ID
  • Don't manually edit fetched columns (Theme, Name, Pieces, etc.) - they could be overwritten on updates
  • Don't use invalid set numbers - they must be valid Lego sets
  • Don't delete columns - hide them if you don't want to see them
  • Don't add sets with the "-1" suffix in the set number field
Understanding Columns
▼
Manual Entry (Columns A-E):
  • Set Number, Condition, Status, Purchase Price, Quantity
Auto-Fetched (Columns F-M):
  • Theme, Name, Pieces, Released, Retired, MSRP, Value, Last Updated
Converting to Table
▼
  1. Select header row by clicking 1 on left, right-click and choose remove filter
  2. Select instruction row, right-click and choose Delete row
  3. Select Format > Convert to Table in Navigation
